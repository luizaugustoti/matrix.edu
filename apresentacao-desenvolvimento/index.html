1) Conexão com o banco

from supabase import Client, create_client
from app.configuracoes.config import settings


def get_supabase_client() -> Client:
    if not settings.supabase_configured:
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail="Supabase nao configurado. Preencha o arquivo backend/.env.",
        )

    return create_client(settings.supabase_url, settings.supabase_service_role_key)

Esse trecho centraliza a conexão do backend com o Supabase. Ele valida se as variáveis de ambiente estão configuradas e cria um cliente para que os serviços consultem ou gravem dados de forma segura.

2) Consulta ao banco

def listar_unidades(cliente: Client) -> list[dict]:
    try:
        resposta = (
            cliente.table("unidades")
            .select("*")
            .eq("ativo", True)
            .order("nome")
            .execute()
        )
        return resposta.data or []
    except Exception as error:
        _tratar_erro_banco(error)
        return []

Aqui a API consulta a tabela unidades, filtra apenas registros ativos e ordena por nome. Esse padrão é usado para listar dados reais do banco e devolver para a interface do sistema.
