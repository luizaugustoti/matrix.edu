# Modulo Busca Ativa (Back-end)

## O que faz
Gerencia casos de acompanhamento de estudantes.

## Problemas que resolve
- Falta de historico estruturado de acompanhamento

## Telas relacionadas (front)
- Lista de casos e detalhe de acompanhamento

## Regras de negocio
- Priorizacao de casos
- Registro de interacoes

## Arquivos principais
- rotas de casos
- servicos de acompanhamento
- schemas de caso

## Como conversa com o front
Disponibiliza API para consulta e atualizacao de casos.

## Exemplo de uso
`PATCH /busca-ativa/casos/{id}` para atualizar status.
