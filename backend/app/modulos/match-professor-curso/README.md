# Modulo Match Professor x Curso (Back-end)

## O que faz
Calcula sugestoes e confirma alocacao docente.

## Problemas que resolve
- Dificuldade de distribuicao manual

## Telas relacionadas (front)
- Painel de sugestoes e confirmacao

## Regras de negocio
- Compatibilidade de area
- Limites de carga horaria

## Arquivos principais
- rotas de sugestao
- servicos de match
- schemas de alocacao

## Como conversa com o front
Retorna sugestoes e recebe confirmacoes de alocacao.

## Exemplo de uso
`GET /match-professor-curso/sugestoes`.
