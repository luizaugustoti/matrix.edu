# Modulo Busca Ativa

## O que este modulo faz
Ajuda a identificar e acompanhar estudantes que precisam de acompanhamento.

## Problemas que resolve
- Falta de acompanhamento centralizado
- Dificuldade de priorizar atendimentos

## Telas esperadas
- Lista de casos
- Detalhe de acompanhamento

## Regras de negocio esperadas
- Classificacao por prioridade
- Registro de historico de acoes

## Arquivos principais
- `paginas/`, `componentes/`, `servicos/`, `tipos/`, `validacoes/`

## Comunicacao com o back-end
Envia e busca dados de acompanhamento pela API.

## Exemplo de uso
Equipe registra contato com estudante e atualiza status do caso.
