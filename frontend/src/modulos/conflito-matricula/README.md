# Modulo Conflito de Matricula

## O que este modulo faz
Detecta conflitos de matricula e apoia resolucao.

## Problemas que resolve
- Matriculas sobrepostas ou invalidas
- Falta de visao central de erros

## Telas esperadas
- Lista de conflitos
- Tela de resolucao por aluno

## Regras de negocio esperadas
- Identificar choque de horarios
- Aplicar regras institucionais de prioridade

## Arquivos principais
- `paginas/`, `componentes/`, `servicos/`, `tipos/`, `validacoes/`

## Comunicacao com o back-end
Consome endpoints de analise e resolucao de conflitos.

## Exemplo de uso
Secretaria filtra conflitos e aplica resolucao orientada.
