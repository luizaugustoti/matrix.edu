# Modulo Match Professor x Curso

## O que este modulo faz
Apoia distribuicao de professores em cursos/turmas com criterios definidos.

## Problemas que resolve
- Alocacao manual demorada
- Falta de padrao para decisao

## Telas esperadas
- Lista de professores e cursos
- Sugestoes de match

## Regras de negocio esperadas
- Compatibilidade por area
- Restricoes de carga horaria

## Arquivos principais
- `paginas/`, `componentes/`, `servicos/`, `tipos/`, `validacoes/`

## Comunicacao com o back-end
Consulta sugestoes e confirma alocacoes pela API.

## Exemplo de uso
Coordenacao analisa sugestao automatica e aprova distribuicao.
